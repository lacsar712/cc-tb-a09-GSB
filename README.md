# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

交评时必须从审评员维护的**香气词库**中勾选香气词，数量不少于审评员设定的最少词数。勾选原文随审评行存档，事后增删词库条目不影响已存勾选。观察员可查看词库与已存勾选，但不能维护词库、不能交评。顶栏「香气词库」进入词库专页。

这是制茶审评，不是菜谱，也不是饮食记录。

## 端口

| 服务 | 地址 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| taster | tea123456 | 可审评 |
| observer | look123456 | 只看 |

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏「香气词库」打开专页：种子含板栗、花香，交评最少词数为 2。
5. taster 交评只勾一个香气词被服务端拒绝；勾满板栗、花香两个后成功，新行与审评列表保留当时勾选。
6. 在词库删除板栗后，已存审评行仍显示板栗；observer 能看词库与已存勾选，但看不到维护表单，直接 POST 维护/交评接口返回 403。
