# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

交评时必须从**香气词库**勾选审评员设定的最少词数；勾选原文随审评行存档，事后增删词库条目不影响已存勾选。顶栏「香气词库」为词库专页：审评员可增删词条、调整最少词数；观察员只能查看词库与已存勾选，不能维护词库、不能交评。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 香气词库初始含「板栗」「花香」，交评最少词数为 2。
5. 交评只勾 1 个香气词提交失败（提示至少 2 个）；勾满 2 个后成功，新行与详情页保留当时勾选原文。
6. 勾选词必须来自词库；勾选内容存的是原文快照，事后删除词条不影响已存行/详情。
7. 观察员能进香气词库专页、查看词条与已存勾选，但加词、删词、改最少词数、交评一律被拒（403）。
